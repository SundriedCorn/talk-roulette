# Talk Roulette

One button. It picks at random from 50 conversation questions and 50 single words,
pulled from tech, science, space, sports, food, travel, nature, music, art, history,
psychology, work and everyday life.

Each prompt is chosen to keep someone talking for at least a minute.

**Live:** https://sundriedcorn.github.io/talk-roulette/

- `index.html` — the page
- `data.js` — the 100 prompts
